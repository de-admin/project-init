# Changelog

Changes for each release of the project-init plugin, newest first. Changes to the documentation of this
repository are in `docs/log.md`.

## 0.1.0 – 21/10/2026

First release.

- Skill `project-init`: modes `new`, `adopt`, `extend` and `review`.
- Grilling: 5 project types, 24 features (F1–F24), 12 questions (Q1–Q12), at most 3 rounds of 4 questions.
- Templates for `README.md`, `CLAUDE.md`, `AGENTS.md` and the OKF v0.2 `docs/` bundle (root index, log,
  setup record, current-state page, line index, overview, open items, decision).
- Checker `check_okf.py` 0.1.0, copied into each project as `tools/check_okf.py`.
